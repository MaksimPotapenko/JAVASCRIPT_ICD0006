# Assignment 7: Vue Nutikas Client

Vue 3 + TypeScript frontend for the hosted Nutikas backend at `https://nutikas.akaver.com/api/v1`.

## Features

- JWT login and registration with refresh-token renewal
- Public event catalogue, contest detail, team registration, and result pages
- QR-based participant marking form with optional coordinate capture
- Organiser workspace for contests, classes, checkpoints, QR print view, teams, members, and markings

## Scripts

```bash
npm install
npm run dev
npm run build
```
