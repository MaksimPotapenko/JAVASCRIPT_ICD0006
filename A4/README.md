# Assignment 4: Vue 3 Todo Client

Vue 3 + TypeScript frontend for the TalTech Todo backend at `https://taltech.akaver.com/api/v1.0`.

## Features

- JWT login and registration
- Refresh-token based session renewal
- Vue Router protected routes
- Pinia stores for auth and Todo data
- CRUD for categories, priorities, and tasks

## Scripts

```bash
npm install
npm run dev
npm run build
```
