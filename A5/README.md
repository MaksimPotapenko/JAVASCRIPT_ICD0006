# Assignment 5: React Todo Client

React + TypeScript frontend for the TalTech Todo backend at `https://taltech.akaver.com/api/v1`.

## Features

- JWT login and registration
- Refresh-token based session renewal
- React Context + reducers for auth and Todo state
- React Router protected routes without property drilling
- CRUD for categories, priorities, and tasks

## Scripts

```bash
npm install
npm run dev
npm run build
```
