# Assignment 6: Express Todo API

Express.js backend that reimplements the Todo API used by the coursework frontend apps.

## Features

- JWT login and register flows
- refresh-token based session renewal
- protected CRUD for categories, priorities, and tasks
- JSON file persistence for local Docker deployment

## Scripts

```bash
npm install
npm start
```
